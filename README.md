# 🚀 DataLemur SQL Practice & Solutions

Welcome to my repository dedicated to solving SQL interview questions from **[DataLemur](https://datalemur.com/)**. 

This repository serves as a personal log of my daily problem-solving journey, track progress, and organize structured SQL notes and techniques across **Easy**, **Medium**, and **Hard** difficulty levels.

---

## 📌 What I Do in This Repository

* **Daily Problem Solving:** Practice writing clean, efficient, and production-ready SQL queries across various platforms (PostgreSQL syntax).
* **Topic Categorization:** Implement core to advanced analytical techniques including:
  * **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, and aggregate windowing (`AVG() OVER ()`).
  * **Aggregation & Grouping:** `GROUP BY`, `HAVING`, and statistical modes (`MODE() WITHIN GROUP (...)`).
  * **Joins & Set Logic:** Inner/Outer joins, `CROSS JOIN` tricks for scalar/aggregate attachment, and CTE-based filtering (`WHERE EXISTS`, `IN`).
  * **Date/Time Manipulation:** `EXTRACT()`, `MAKE_DATE()`, date arithmetic, and rolling timeline aggregations.
* **Knowledge Organization:** Maintain technical cheat sheets and notes on fundamental SQL principles for quick reference during interview prep.
